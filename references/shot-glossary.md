# คำศัพท์ช็อตและมุมกล้อง (ใช้ให้ตรงกันทุกตาราง)

## ขนาดภาพ (Shot Size)
| ตัวย่อ | ชื่อเต็ม | ความหมาย |
|---|---|---|
| ELS | Extreme Long Shot | ไกลมาก เห็นสถานที่กว้าง คนตัวเล็ก ใช้เปิดฉาก |
| LS | Long Shot / Wide | เห็นคนเต็มตัวและฉากรอบตัว |
| MLS | Medium Long Shot | ตั้งแต่เข่าขึ้นไป |
| MS | Medium Shot | ตั้งแต่เอวขึ้นไป |
| MCU | Medium Close-Up | ตั้งแต่อกขึ้นไป (แบบคนพูดหน้ากล้อง) |
| CU | Close-Up | ใบหน้าเต็มเฟรม หรือสินค้าเต็มเฟรม |
| ECU | Extreme Close-Up | เฉพาะส่วน เช่น ตา ปาก ผิว เนื้ออาหาร |
| Insert | Insert / Cutaway | ภาพรายละเอียดแทรก เช่น มือกดปุ่ม ป้ายราคา |
| OTS | Over the Shoulder | ถ่ายข้ามไหล่คนหนึ่งไปหาอีกคน |
| POV | Point of View | มุมมองสายตาตัวละคร |
| Two-shot | Two-shot | มีคน 2 คนในเฟรม |
| Graphic | Motion Graphic / Text card | ภาพกราฟิกหรือการ์ดตัวหนังสือล้วน |
| Screen | Screen record | ภาพหน้าจอมือถือหรือคอมพิวเตอร์ |
| UGC | UGC selfie | ถือกล้องถ่ายตัวเองแบบรีวิว |

## มุมกล้อง (Angle)
| มุม | ความหมาย |
|---|---|
| Eye level | ระดับสายตา เป็นกลาง |
| High angle | กดลงจากด้านบน ตัวแบบดูเล็กลง |
| Low angle | เงยขึ้นจากด้านล่าง ตัวแบบดูยิ่งใหญ่ |
| Top shot / Bird's eye | ตั้งฉากจากด้านบน นิยมกับอาหารและสินค้าวางพื้น |
| Dutch angle | เอียงกล้อง สร้างความรู้สึกไม่มั่นคง |
| Profile | ด้านข้าง |
| Frontal | หน้าตรง |

## การเคลื่อนกล้อง (Movement)
| คำ | ความหมาย |
|---|---|
| Static | กล้องนิ่ง |
| Pan | หมุนซ้ายขวา |
| Tilt | ก้มเงย |
| Push in / Dolly in | เคลื่อนเข้าหาตัวแบบ |
| Pull out / Dolly out | ถอยออก |
| Tracking / Follow | เคลื่อนตามตัวแบบ |
| Orbit | หมุนรอบตัวแบบ |
| Handheld | ถือมือ มีการสั่นเล็กน้อย |
| Gimbal | เคลื่อนนิ่มด้วยกิมบอล |
| Zoom in / out | ซูมเลนส์ (ภาพแบนกว่า dolly) |
| Whip pan | หมุนเร็วจนภาพเบลอ ใช้เป็นทรานซิชัน |
| Crane / Drone | ยกสูงหรือมุมโดรน |

## เทคนิคตัดต่อ (ใส่ในช่อง Notes)
Jump cut · Match cut · J-cut / L-cut (เสียงนำหรือตามภาพ) · Speed ramp · Slow motion · Split screen · Freeze frame · Zoom transition · Glitch · Text pop / Kinetic type · B-roll overlay · Picture in picture
